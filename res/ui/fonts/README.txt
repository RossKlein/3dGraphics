Place a TTF font file here named:

  Roboto-Regular.ttf

Roboto is a free font available from Google Fonts:
  https://fonts.google.com/specimen/Roboto

Download → extract → copy Roboto-Regular.ttf into this folder.

ControlsHudLayer will call:
  rmlUi.loadFont("res/ui/fonts/Roboto-Regular.ttf")

If no font is loaded, RmlUi will render no text (silent failure).
